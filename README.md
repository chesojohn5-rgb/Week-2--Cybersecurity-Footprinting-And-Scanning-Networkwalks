# Week-2--Cybersecurity-Footprinting-And-Scanning-Networkwalks


📌 Module Overview
This Project Focuses On Footprinting and Scanning using The authorized Networkwalks Website and Local Area Hosts and Sabnets.

🎯 Objectives
The main objectives of this project are to:

Footprint Using multiple Kali Linux tools, ( 6 tools on networkwalks.com)

Zenmap Based Network Scanning

Steps Taken.

Step 1:

 Run whois to find the domain registration details.

 Step 2:
 Run whatweb to fingerprint the web technologies

 Step 3:
  Run nslookup to resolve the domain to its IP address.
  
  Step 4:
   Run curl -I to read the HTTP response headers.

   Step 5:
    Run wafw00f to detect a Web Application Firewall.

    Step 6:
     Run dnsrecon to enumerate all DNS records
